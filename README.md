# 📈 exchange-proto — 미니 증권거래소 프로토타입

졸업프로젝트용 검증 프로토타입. 이용자가 1명이어도 시장이 살아있게 만드는 것이 목표.

## 실행

```bash
npm install   # 최초 1회 (express, ws)
npm start     # http://localhost:3100
```

테스트 (서버 없이 헤드리스 검증):

```bash
npm test
```

## 뭐가 돌아가는가

```
┌─────────────────────────────────────────────────────────┐
│ World (1틱 = 1초)                                        │
│                                                         │
│  MarketSim ──적정가──▶ MarketMaker ──양방향 호가──▶ OrderBook │
│  (국면전환 랜덤워크)        (스프레드/재고 관리)              │
│                                                         │
│  Persona Bots × 5 ──지정가 주문──▶ OrderBook              │
│    🚀 단타충(모멘텀) 🐻 불곰(역행) 🌳 존버(가치)              │
│    😰 겁쟁이(패닉) 📊 기관(소극적)                          │
│                                                         │
│  OrderBook ──체결──▶ 계좌/잔고 + 커뮤니티 피드              │
└─────────────────────────────────────────────────────────┘
        REST API + WebSocket (1초마다 스냅샷 브로드캐스트)
```

- **매칭 엔진** (`src/engine.js`): 가격-시간 우선, 부분체결, 미체결 주문 취소
- **시세 시뮬레이터** (`src/sim.js`): calm/bull/bear/wild 국면 전환 + 점프
- **마켓메이커** (`src/mm.js`): 항상 양방향 호가. 변동성↑ → 스프레드 확대.
  재고 쌓이면 호가 하향 스큐. 중심가는 `0.7×최근체결가 + 0.3×적정가`라서
  **이용자가 대량 매수하면 가격이 실제로 밀려오름**
- **페르소나 봇** (`src/bots.js`): 매매는 규칙 기반(모멘텀/역행/가치/패닉/소극),
  글은 템플릿 + 실제 시세 숫자 삽입. 체결/급변/손익 마일스톤에 반응해 글 쓰고 서로 댓글 담

## API

| Method | Path | 설명 |
|---|---|---|
| GET | `/api/snapshot` | 전체 상태 (가격/호가/체결/내잔고/피드/차트) |
| POST | `/api/order` | `{side:'buy'|'sell', price, qty}` 지정가 주문 |
| POST | `/api/orders/:id/cancel` | 미체결 주문 취소 |
| POST | `/api/post` | `{text}` 커뮤니티 글 (봇이 댓글 달 수 있음) |

WebSocket `/` 연결 시 매 틱 스냅샷 푸시.

## LLM으로 진화하는 지점 (나중)

전부 인터페이스 경계를 만들어 둠:

1. **글 생성**: `Bot.render()`의 템플릿 렌더링 → `PostGenerator`로 교체
2. **매매 판단**: `Bot.act()`의 switch문 → LLM 의사결정으로 교체
3. **기억**: `world.trades` + `feed.posts`가 이미 이벤트 로그 → 에이전트 memory corpus로 그대로 사용 가능

## 확인 포인트 (데모 시)

1. 새로고침 → 1초마다 가격/호가/체결/피드가 살아 움직임
2. 매수 폼에서 최대 수량 매수 → 호가창이 순식간에 소화되고 다음 틱에 가격 상승
3. 커뮤니티에 글 쓰기 → 봇이 댓글 달 확률
4. `npm test` → 헤드리스 검증 결과 콘솔 출력
